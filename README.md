# ⭐ Python Calculator (Team-2)

Python으로 구현하는 **CLI 기반 계산기 프로그램**입니다.
이 프로젝트는 Git을 활용한 **branch 기반 협업 workflow**를 학습하기 위한 Team2의 프로젝트입니다.
---
덧셈 - 이설아 <br>
뺄셈 - 유소영 <br>
곱셈 - 박주혁 <br>
나눗셈 - 유소영 <br>


# 🛠️ 구현 기능

사칙연산 기능

```
1. 덧셈
2. 뺄셈
3. 곱셈
4. 나눗셈
```

예시 실행 결과

```
첫번째 숫자 입력: 10
연산 선택 (+ - * /): +
두번째 숫자 입력: 5
결과: 15
다시 실행하시겠습니까? (y/n): n
```

추가 기능

```
- 잘못된 입력 처리 (문자열은 실행 불가)
- 0으로 나누기 불가능
- 반복 실행 기능
```

### issue 양식
제목 <br>

`체크란 형태로 작성`

# 📌 Commit 규칙

`[태그명] 내용` 으로 작성

| 태그 | 제목 |
|------|------|
| Feat | 새로운 기능 추가 |
| Fix | 버그 수정 |
| Docs | 문서 수정 |
| Style | 코드 포맷팅, 세미콜론 누락, 코드 변경이 없는 경우 |
| Refactor | 코드 리팩토링 |
| Test | 테스트 (테스트 코드 추가, 수정, 삭제, 비즈니스 로직에 변경이 없는 경우) |
| Chore | 위에 걸리지 않는 기타 변경사항 (빌드 스크립트 수정, assets image, 패키지 매니저 등) |
| Comment | 필요한 주석 추가 및 변경 |
| Init | 프로젝트 초기 생성 |
| Rename | 파일 혹은 폴더명 수정하거나 옮기는 경우 |
| Remove | 파일을 삭제하는 작업만 수행하는 경우 |

예시
```
[Feat] 덧셈 기능 구현 완료
[Feat] 뻴셈 기능 구현 완료
[Fix] 나눗셈 시 결과가 반올림되지 않는 문제 해결
```
